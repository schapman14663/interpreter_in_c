# Feature List

- C like syntax
- Variable bindings
- Integers and Booleans
- Arithmetic Expressions
- Built in functions
- First Class and Higher Order functions
- Closures
- String Data Structure
- Array Data Structure
- Hash Data Structure

## Binding Examples:


int variable: ``let age = 1;``
string variable: ``let name = "Sam";``
Expression: ``let result = 10 * (2 + 3);``

Array: `let newArr = [0, 1, 2, 3]`
Hash: `let idHash = {"name": "Steven", "age": 31 }`

Access for Arrays and Hashes: 

`newArr[2]` => 2
`idHash["age"]` => 31

Functions: 

new function: `let add = fn(a, b) {return a + b}`

call function: `add(5,6)` => 11
